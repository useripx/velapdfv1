# PANDUAN PENGGUNAAN SKILL REQUIREMENT ANALYSIS

1. Masukkan dokumen mentah kebutuhan atau rangkuman wawancara pengguna ke direktori input.
2. Jalankan prosedur analisis kebutuhan sesuai tahapan di `SKILL.md`.
3. Validasi hasil menggunakan script `scripts/validate-requirements.ps1`.
4. Simpan spesifikasi final ke `Docs/Requirements_Specification.md`.
